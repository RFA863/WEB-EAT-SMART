# WEB EAT SMART 🍽️🧠

## Brief Description

**Eat Smart** is a web application designed to provide personalized food recommendations to users. By leveraging AI, this application aims to help users choose meals that suit their preferences and needs, promoting smarter and healthier eating habits. 🍎🥦🥕

---

## Application Features ✨

* **Homepage:** The main page presenting an introduction to the application.
* **Sign Up & Log In:** User authentication system to access personalized features.
* **Personalization:** Feature for users to input food preferences or other relevant data.
* **Food Recommendations:** Displays tailored food recommendations based on user data.
* **Smart Chat:** An AI-based chat assistant to answer user questions about food or nutrition.
* **Settings:** Page for managing user account settings.

---

## Technologies Used 💻

* **Frontend Framework:** React
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **Routing:** React Router DOM
* **Linting:** ESLint
* **Package Manager:** npm

---

## How to Run the Application 🚀

To run this application in your local development environment, follow these steps:

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/RFA863/web-eat-smart.git](https://github.com/RFA863/web-eat-smart.git)
    cd WEB-EAT-SMART
    ```

2.  **Install Dependencies:**
    Ensure you have Node.js and npm installed. Run the following command in the project's root directory:
    ```bash
    npm install
    ```
    This command will download and install all the necessary packages listed in `package.json`.

3.  **Run the Development Server:**
    Once the installation is complete, start the development server using Vite:
    ```bash
    npm run dev
    ```
    This command will start the local development server (usually at `http://localhost:5173`) and open the application in your default browser. The application will automatically refresh when you make changes to the code.

4.  **Build for Production (Optional):**
    If you want to create an optimized production build, run:
    ```bash
    npm run build
    ```
    The build output will be stored in the `dist` directory.

5.  **Preview Production Build (Optional):**
    To preview the production build locally, run:
    ```bash
    npm run preview
    ```
   

6.  **Linting (Optional):**
    To check and fix code style issues using ESLint, run:
    ```bash
    npm run lint
    ```
   

Enjoy using Eat Smart! 🎉
